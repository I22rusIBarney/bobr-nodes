# Bobr Nodes — правила для изменений

## Версии и история изменений

Версия бота живёт в `bot/changelog.json` (новые выпуски сверху). Каждый PR, который меняет поведение для
пользователя, добавляет запись или дополняет верхнюю, если она ещё не выпущена:

- **+0.1** — минорное: новая настройка, событие, улучшение, исправления (2.5 → 2.6).
- **+1.0** — крупное: новая большая возможность или заметная переделка (2.6 → 3.0).
- Пункты `items`: `kind` — `new` (новое), `better` (лучше), `fix` (исправлено); текст — для пользователя, по-русски,
  без внутренних названий функций и файлов.
- Тест `tests/test_changelog.py` проверяет порядок и формат.

После обновления бот сам пишет администраторам, что нового, — по этой истории.

## Уведомления

Все сообщения пользователям о событиях — через `bot/notify.py` (`Notifier.emit` с типом из `TYPES`), не через
`bot.send_message` напрямую: так событие попадает в ленту колокольчика и учитывает настройки получателя.
